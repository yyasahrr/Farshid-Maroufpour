# بازیابی خطا

- OTP اشتباه: کد خالی، فوکوس خانه اول، تلاش محدود. منقضی: CTA درخواست کد تازه. هرگز ورود با کد ثابت/بدون درخواست.
- مشکل شبکه زمان‌بندی: انتخاب خدمت و روز محفوظ، دکمه «تلاش دوباره». روز پر: CTA بررسی روز بعد.
- تغییر زمان توسط مشتری دیگر: نگهداری تراکنشی رد می‌شود، متن «این زمان لحظاتی پیش رزرو شد» و لیست زمان‌های تازه؛ بازگشت به خانه ممنوع.
- انقضای نگهداری: تایمر صفر، دکمه پرداخت غیرفعال، «بررسی زمان‌های جدید»؛ دادهٔ خدمت باقی می‌ماند.
- تغییر نسخه قوانین: API نسخهٔ نامعتبر را رد می‌کند؛ درخواست تازه با نسخهٔ جاری.
- پرداخت ناموفق: PENDING یا FAILED به مشتری نشان داده می‌شود، بازگشت به صفحه پرداخت/پیگیری؛ وعده تأیید پیش از verify ممنوع.
- سشن منقضی: بازشدن OTP مجدد، بدون پاک‌کردن بی‌مورد انتخاب‌ها.
- فروشگاه بدون محصول: empty state صادقانه و مسیر تماس؛ پرداخت آنلاین فروشگاه ادعا نمی‌شود.
